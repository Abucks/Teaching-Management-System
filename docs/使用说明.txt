================================================================
  教学管理系统 v1.3.1  —  使用说明（Windows / macOS 跨平台版）
================================================================

一、这是什么
  一套本地教学管理工具（PySide6 桌面程序），数据保存在本机 SQLite 数据库，
  无需联网。四大模块：

    👥 学生管理   班级总览 → 点入班级查看该班学生（磁贴，姓名在头像下方完整显示）
    📅 排课管理   月历标记有课的日子 → 点日期展开当天课程时间安排
    💬 便签墙     像剪贴板/贴纸便签：文字、表格、图片都能贴，统一展示
    📊 成绩管理   统计图表（分数分布/科目对比/趋势图）+ 学生个人成绩报告

二、界面与操作（v1.3.0 新界面）
  1) 字体
     · 界面与图表统一使用 MiSans（若系统已安装）；macOS 无 MiSans 时自动使用
       苹方 PingFang SC；Windows 回退微软雅黑、Linux 回退思源黑体。
     · 也可把 MiSans.ttf 等字体文件放进程序目录下的 fonts\ 文件夹，程序会自动加载。

  2) 学生管理（两级浏览 + 导航栏）
     · 首页按班级聚合成「班级磁贴」（显示人数与标签统计）
     · 点击班级磁贴 → 平滑滑入该班学生列表（带过渡动画）
     · **页面导航栏**（磁贴上方浅蓝色条）：
         - 「← 上一页」回到上一个浏览过的页面（无可返回时自动隐藏/禁用）
         - 面包屑路径「🏠 班级总览 › 高一(1)班 › 🔍 搜索：张」中，
           **点击任意一段即可跳回那一页**（其后的记录自动丢弃）
         - 「🏠 班级总览」一键回到首页并清空前进历史
     · 顶部搜索框可跨班级搜索学生（自动切到结果页，清空即返回）
     · 学生磁贴：头像在上，**完整姓名显示在头像正下方**，下方依次为学号/班级/标签/头衔
     · 班级磁贴右键「✏️ 编辑班级名称」可批量重命名该班

  3) 排课管理（月历视图）
     · 月历中**有课的日期**显示「N 节课」徽标并高亮；今天为红色虚线框
     · 点选某个日期，右侧平滑展开**当天课程的详细时间安排**（时间、科目、教师、地点、备注）
     · 每条课程右侧有「✏️ 编辑 / 🗑 删除」按钮，双击课程也可编辑
     · 顶部「◀ 年月 ▶」切换月份，「今天」快速回到当天

  4) 便签墙（原反馈系统，改为剪贴板式便签）
     · 支持三种便签：📝 文字、📊 表格、🖼 图片；**不再限定日期/班级/范围，全部统一展示**
     · 「📋 粘贴新建」：直接读取剪贴板内容生成便签
         - 剪贴板是图片（截图、微信图片）→ 生成图片便签
         - 剪贴板是表格（从 Excel/WPS 复制）→ 自动识别为表格便签
         - 其他 → 生成文字便签
     · 「➕ 新建便签」：打开编辑器，可切换文字/表格/图片三种类型；
         编辑器内按 Ctrl+V 会**智能识别**剪贴板类型并自动切换页面；
         表格页支持加行/加列/删行/删列、从剪贴板粘贴整表；
         图片页支持粘贴剪贴板图片、选择文件、直接把图片拖进来，并可写图片说明
     · 每条便签可「📌 置顶」（置顶的排在最前）、✏️ 编辑、🗑 删除、📋 复制内容
     · 图片便签点击可查看大图并复制回剪贴板
     · 便签底色可选（贴纸风格柔和色），右上搜索框可搜索便签内容

  5) 每个磁贴都能编辑（重点）
     所有磁贴（班级、学生、便签、成绩、当天课程）都有两种编辑入口：
       · 鼠标悬停在磁贴上，右上角出现 ✏️（编辑）与 🗑（删除）小按钮
       · 右键磁贴弹出菜单，含「✏️ 编辑 / 🗑 删除」等操作
     成绩磁贴「✏️ 编辑」会打开该学生的成绩编辑表，可逐条新增/修改/删除成绩。

  6) 删除（防止数据越积越多）
     · 各模块顶部都有红色「🗑 删除」按钮，支持单个与批量删除（勾 1 个即单个）
     · 学生管理删除学生时会**自动级联清理其名下全部成绩**
     · 便签删除时其图片文件也会一并清理
     · 所有删除均有二次确认、不可恢复，建议先备份（见第五节）

三、如何运行
  【Windows】
    方式1（推荐）：双击 exe 直接运行（首次启动解压需等待 10~30 秒）
    方式2：安装 Python 3.10+ 后
        pip install PySide6 matplotlib openpyxl python-docx xlrd
        python teaching_manager.py

  【macOS】
    方式1：打开 DMG 安装包，把「教学管理系统」拖入 应用程序(Applications)。
        首次打开若提示“无法验证开发者”：访达中【右键应用 → 打开】，
        或执行 xattr -dr com.apple.quarantine "/Applications/教学管理系统.app"
    方式2：安装 Python 3.10+ 后（终端）
        pip install PySide6 matplotlib openpyxl python-docx xlrd
        python3 teaching_manager.py
    说明：DMG 必须在 Mac 上生成（PyInstaller 不支持跨平台编译）。
        打包目录 packaging/macos/ —— 在 Mac 上执行
        ./build_macos.sh 一键产出 .app 与 .dmg；详见其中 README-macOS.md。

四、数据文件说明（跨平台自动定位）
  目录选择顺序：
      1) 环境变量 TMS_DATA_DIR 指定目录
      2) 程序所在目录（便携模式，Windows exe 同目录）
      3) 系统用户数据目录（程序目录不可写时）
         · macOS：~/Library/Application Support/TeachingManager/
         · Windows：%APPDATA%\TeachingManager\
  目录内容：
      teaching_management.db   —— 主数据库（学生/课程/便签/成绩）
      feedback_images\         —— 便签图片（v1.3.0 新增，随便签一起备份）
      config.json              —— 配置（预留）
  菜单【文件 → 打开数据目录】可直接定位；「关于」显示当前数据目录与模式。
  备份：复制整个数据目录即可（含 feedback_images 文件夹）。

五、导入学生信息表格格式
  支持：.xlsx  .xls  .docx(表格)  .csv
  表头建议按顺序使用：  学号 | 姓名 | 班级 | 标签 | 头衔
    · 可识别：学号/编号/ID、姓名/名字、班级/class、标签/tag、头衔/title
    · 标签、头衔可留空，多个值用逗号（中英文均可）分隔
    · 允许空行；学号重复会自动去重并在结果里提示

六、导入成绩表格格式
  支持：.xlsx  .xls  .csv
  表头建议：姓名 | 科目 | 成绩 | 考试日期 | 考试类型
    · 考试日期支持 Excel 真实日期单元格与文本日期（2026-06-01 / 2026/6/1），
      空白日期自动取当天
    · 成绩按“姓名”关联学生；未导入的学生姓名也会保存为无关联成绩

七、注意事项
  · .doc 旧版 Word 仅 Windows + 已安装 Microsoft Word 时可用；
    macOS 请先另存为 .docx（程序会给出明确提示）
  · 便签图片保存在数据目录的 feedback_images 内，删除便签会同步删除图片文件；
    手工挪动数据库时请连同该文件夹一起复制
  · 高分屏（Retina）已适配；中文字体按平台自动选择，图表中文不会出现方块
